# Міні-ERP «Зелена Полиця»

Навчальний тренажер ERP-системи до курсу «Бізнес-інформатика» (ДУІКТ, спеціальність 073 «Менеджмент»).

**▶ Відкрити тренажер: https://artem-zavgorodniy.github.io/erp-sandbox/**

Тренажер показує головну ідею ERP: у компанії одна спільна база, тому кожна дія — замовлення, відвантаження, рахунок, закупівля — одразу видна в усіх модулях, і нікому не треба пересилати документи чи звіряти числа.

## Модулі

| Модуль | Що робить |
|---|---|
| Продажі | замовлення клієнтів; підтвердження резервує товар на складі; «Шлях документа» показує, крізь які модулі пройшло замовлення |
| Склад | відвантаження й залишки: на складі, зарезервовано, доступно, мінімум |
| Закупівлі | товари нижче мінімуму й замовлення постачальникам |
| Бухгалтерія | рахунки клієнтам створюються самі в момент відвантаження; оплати й витрати на закупівлі |
| Звіт | виручка, вартість складу, замовлення в роботі |
| Журнал | усі події в тому порядку, як вони записані в базу |

## Дані

Товари, ціни, собівартість і постачальники взяті з навчальної бази «Зеленої Полиці» — вигаданого інтернет-магазину. Початкові залишки й клієнти — навчальні, реальних людей не стосуються.

## Технічно

Одна сторінка без зовнішніх бібліотек. Прогрес зберігається в браузері студента (localStorage), нікуди не надсилається; кнопка «Почати спочатку» повертає початковий стан.
